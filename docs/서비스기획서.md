# 있는대로 서비스 기획서

## 서비스 한눈에 보기

있는대로는 냉장고 재료를 기록하고, 지금 만들 수 있는 요리부터 식단과 장보기까지 이어 주는 1인 가구용 웹 서비스입니다.

사용자가 해결하려는 질문은 세 가지입니다.

1. 냉장고에 무엇이 있지?
2. 오늘 무엇을 해 먹지?
3. 다음에 무엇을 사야 하지?

## 주요 사용자

- 혼자 살며 직접 요리하지만 재료를 자주 잊는 사람
- 배달비와 식비를 줄이고 싶은 20~30대
- 복잡한 재고 관리보다 빠른 추천과 간단한 기록을 원하는 사람

## 문제와 해결

| 문제 | 해결 방식 |
| --- | --- |
| 보유 재료를 기억하기 어렵다 | 냉장고에 재료와 소비기한을 기록한다. 기본 양념은 별도 영역으로 구분한다. |
| 메뉴 결정에 시간이 든다 | “지금 바로 만들기”와 “조금만 장보기”로 선택을 단순화한다. |
| 식단과 장보기가 따로 논다 | 식단에서 부족한 재료를 계산해 장보기 목록으로 연결한다. |
| 직접 해 먹은 효과가 보이지 않는다 | 요리 완료 시 주간·월간 절약 금액을 보여 준다. |

## 핵심 가치

> 있는 재료를 먼저 쓰고, 부족한 것만 사도록 돕는다.

- 입력 부담이 작아야 한다.
- 결과의 근거가 보여야 한다.
- 추천 이후 요리·식단·장보기 행동까지 연결되어야 한다.
- 사용자를 탓하거나 과장하지 않는다.

## 현재 기능

- 냉장고: 재료·소비기한 관리, 기본 재료 구분, 사진에서 재료 후보 가져오기
- 요리 추천: 바로 만들 결과와 조금만 사서 만들 결과, 실제 레시피 출처 연결
- 식단: 여러 날의 저녁 계획, 즐겨찾기, 메뉴 교체와 완료 처리
- 장보기: 부족한 재료 통합과 구매 상태 관리
- 절약 현황: 요리 완료 1회당 13,000원으로 주간·월간·누적 금액 표시

## 운영 제약

- 계정과 서버 저장소가 없어 기기와 브라우저 사이에 동기화되지 않는다.
- 브라우저 데이터를 지우면 사용자 기록도 사라질 수 있다.
- 추천과 사진 분석은 외부 인공지능 API 상태와 비용에 영향을 받는다.
- KADX 데이터는 CC BY-NC-ND이므로 현재 데이터 기반 기능은 비상업적 범위에서 운영한다.

## 성공 지표

분석 기능을 추가하면 다음을 우선 측정합니다.

- 냉장고 등록 후 추천까지 도달한 비율
- 추천에서 요리 완료까지 이어진 비율
- 식단에서 장보기 목록을 만든 비율
- 일주일 안에 다시 방문한 비율
- 빈 결과와 API 오류 비율
