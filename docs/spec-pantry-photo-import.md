# 냉장고 사진 가져오기 명세

## 목적

영수증이나 장보기 내역 사진에서 재료 후보를 찾아 입력 부담을 줄입니다. 분석 결과를 자동 저장하지 않고 사용자가 확인한 항목만 반영합니다.

## 사용자 흐름

1. 냉장고 화면에서 사진을 고른다.
2. 분석 중 상태를 보여 준다.
3. 찾은 재료 후보와 구매일을 확인 화면에 표시한다.
4. 사용자는 선택 해제, 이름 수정, 항목 추가를 할 수 있다.
5. 확인한 항목만 냉장고에 저장한다.

후보가 없거나 실패하면 이유와 다시 시도할 방법을 안내합니다. 원본 사진은 냉장고 데이터에 보관하지 않습니다.

## 서버 동작

- 경로: POST /api/pantryImport
- 요청: image 데이터 URL
- 응답: 재료 배열과 YYYY-MM-DD 형식 구매일 또는 null
- 인공지능이 품목 후보를 추출한다.
- 레시피에서 5회 이상 등장한 재료 어휘와 대조한다.
- 공통 정규화·보유 판정 규칙으로 이름을 표준화한다.
- 중복을 제거하고 최대 30개를 반환한다.

## 품질과 안전

- 과자, 완제품, 생활용품 등 조리 재료가 아닌 품목은 제외한다.
- 브랜드명과 용량보다 실제 재료명을 우선한다.
- 모호한 결과는 확정값처럼 저장하지 않는다.
- 파일 오류와 네트워크·API 오류를 구분해 안내한다.
- API 키는 서버에서만 사용한다.
- 화면에서 파일 형식과 크기를 검증한다.

## 완료 조건

- 확인 전에는 냉장고가 바뀌지 않는다.
- 수정·선택 해제·추가 후 확정 결과가 그대로 저장된다.
- 모바일 카메라와 파일 선택, 데스크톱 파일 선택에서 동작한다.
- 빈 결과와 오류 뒤에 다시 시도할 수 있다.
