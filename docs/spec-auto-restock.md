# 요리 완료·자동 반영 명세

## 목적

요리를 완료했을 때 사용한 재료와 식단 상태, 절약 기록을 함께 정리합니다. 예상하지 못한 재고 변경을 막기 위해 반영 항목을 먼저 확인합니다.

## 완료 흐름

1. 추천 또는 식단에서 “요리했어요”를 선택한다.
2. 사용한 것으로 판단한 냉장고 재료를 체크 목록으로 보여 준다.
3. 사용자가 제외할 항목을 선택 해제한다.
4. 선택된 재료를 냉장고에서 제거한다.
5. 식단에서 시작한 경우 메뉴를 완료 상태로 표시한다.
6. 절약 기록에 13,000원을 더한다.
7. 직전 작업은 되돌릴 수 있다.

현재 수량 모델이 없으므로 선택된 재료는 이름 기준으로 전량 제거합니다. 이 제약은 확인 화면에서 알려야 합니다.

## 식단과 장보기

- 식단에는 완료 여부만 저장한다.
- 부족한 재료는 현재 냉장고와 미완료 식단으로 매번 다시 계산한다.
- 완료한 메뉴의 재료는 장보기 부족분에서 제외한다.
- 식단이나 냉장고가 바뀌면 저장된 부족분을 재사용하지 않는다.

## 절약 계산

- 한 끼 완료: 13,000원
- 치킨 비교 기준: 30,000원
- 주간: 월요일부터 일요일
- 월간: 같은 연·월
- 누적: 저장된 전체 완료 금액
- 되돌리기: 직전 완료 한 건만 취소

금액은 동기 부여용 고정 추정치이며 실제 지출을 뜻하지 않습니다.

## 저장과 예외

- 상태는 현재 브라우저의 localStorage에 저장한다.
- 저장 실패 시 화면 값만 먼저 바꾸지 않고 오류를 안내한다.
- 오래된 형식과 누락되거나 변형된 값도 안전하게 보정한다.
- 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 사라질 수 있다.

## 완료 조건

- 확인하지 않은 재료는 삭제되지 않는다.
- 완료와 되돌리기 후 냉장고·식단·장보기·절약 값이 일치한다.
- 반복 실행으로 금액이 중복 반영되지 않는다.
- 새로고침 후에도 확정 상태가 유지된다.
