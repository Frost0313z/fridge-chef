냉털 셰프는 무엇인가요?

"냉털"은 냉장고 털기의 줄임말입니다. 애매하게 남은 재료들을 보면서 "이걸로 뭘 해먹지?" 고민하는 순간, 재료만 입력하면 AI가 바로 답을 드립니다.

이용 방법

  1. 1

    재료 입력

    자주 쓰는 재료는 "내 재료함"에 등록해두고, 오늘만 있는 재료는 추가 입력란에 적습니다. (예: 계란, 대파, 두부)

  2. 2

    AI 추천 요청

    만들 분량과 조리 시간을 선택하고 추천받기 버튼을 누르면 AI가 요리를 분석합니다. 한 번에 두 끼 분량을 만들어 다음 끼니까지 해결할 수도 있어요.

  3. 3

    레시피 확인

    추천 요리의 필요 재료와 조리 순서를 바로 확인하고 요리를 시작하면 됩니다.

기술 스택

  • Frontend — HTML / CSS / JavaScript (프레임워크 없이 바닐라로 구현)
  • Backend — Vercel Serverless Functions (Python)
  • AI — OpenAI API (Chat Completions)
  • Deploy — Vercel

자주 묻는 질문

재료를 정확한 계량으로 입력해야 하나요?

아니요. "계란 2개, 대파 조금"처럼 대략적으로만 입력해도 됩니다.

추천 결과가 이상하거나 안 나오면 어떻게 하나요?

재료를 조금 더 구체적으로 입력하거나, 잠시 후 다시 시도해보세요. AI 서버가 혼잡하거나 응답이 지연되는 경우 안내 메시지가 표시됩니다.

제 재료 정보가 저장되나요?

"내 재료함"에 등록한 재료는 편의를 위해 이 브라우저의 로컬 저장소(localStorage)에만 저장됩니다. 서버로 전송되거나 다른 사람에게 공개되지 않으며, 언제든 × 버튼으로 삭제할 수 있습니다. 그 외 그날그날 추가로 입력한 재료는 추천을 생성하는 데만 쓰이고 따로 저장되지 않습니다.

주간 식단의 장보기 리스트, 쿠팡 장바구니에 자동으로 담기나요?

아니요. 리스트의 "쿠팡에서 검색" 링크를 누르면 해당 재료의 쿠팡 검색 결과 페이지가 새 탭으로 열릴 뿐, 장바구니에 자동으로 담거나 결제를 진행하지 않습니다. 실제 담기·구매는 직접 확인하고 진행해주세요.
